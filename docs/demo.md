# Application walkthrough

Open [Known Enough](https://known-enough.vercel.app/) in a current desktop or mobile browser. The hosted app requires approved participant accounts. New accounts need email verification and application access. No local installation or AWS credentials are required.

## Participant workflow

1. Sign in, create a group, and invite a second approved participant by username, verified email, or a recipient-bound link. Accept from the recipient's own account. Use separate browser profiles for separate participants.
2. Create a decision with explicit alternatives. For example, choose a restaurant (**Cedar / Maple**), a date (**2026-11-14 / 2026-11-15**), and a time (**18:00 / 19:00**). Review and accept AI suggestions individually if used.
3. Each participant opens the decision, selects acceptable choices, and saves their own answers. Select at least one common option per topic for a compatible example.
4. Request an outcome. Each required participant reviews and approves the same proposal. The decision remains proposed until the last required approval.
5. Open **Chat**. Select AI consent and use **Post and ask AI** in Decision chat to ask “What is the outcome and who has approved?” Plain **Post message** does not request AI.
6. Use **Private assistant** for a separate conversation. Another participant cannot open that thread. Sharing a message requires a preview and explicit post to Decision chat.

Chat cannot save private answers or approve a proposal. Each participant must perform those actions in the decision view.

## Evaluation access

Judge accounts and their organizer/participant roles must be arranged before evaluation. Supply credentials and any prepared example privately in the submission's testing instructions, not in this repository. Track access preparation and the video in the [submission checklist](hackathon-submission.md#submission-checklist).
