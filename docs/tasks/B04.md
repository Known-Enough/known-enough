### First-slice design boundary

The initial slice verifies Cognito access-token signatures and the configured pool/client before deriving a principal from the signed subject and group claims. A single `deal-table:display:<room-id>` group grants only that room's existing read-only display principal; ambiguous or malformed display scopes fail closed. All other verified subjects are participant candidates, with actual room membership and organizer permissions still enforced by the application. The generic API handler resolves identity before route/body handling, then performs application route authorization before parsing command bodies or reaching idempotency replay. No user-supplied owner ID is accepted.
