## One runner command

After installation and a trusted LIVE03 deployment receipt, the GitHub test job obtains only `KnownEnoughGithubQaTest` temporary credentials. It runs:

```bash
node scripts/live-qa/runner.mjs /tmp/qa-target.json /tmp/qa-receipt.json gh-RUN_ID-ATTEMPT /tmp/qa-report.json
```

It rejects personal profiles/users, primary resource IDs, unrelated endpoints, absent setup, mismatched source SHA/digests and incomplete receipts. It invokes only the synthetic broker, retrieves the current run's login manifest privately, runs Chromium unattended, checks bounded QA logs and always requests run-owned cleanup. No A profile/password, human mailbox, administrative admission command or participant approval is needed. Installed approved envelope and actual workload role are prerequisites. Absent setup writes a sanitized BLOCKED_OR_FAILED report and exits 1; it makes no AWS request. LIVE03 provides A/B's GitHub launch interface.
